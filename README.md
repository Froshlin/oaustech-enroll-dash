OAUSTECH Enrollment Dashboard
Project Information

Live URL: https://oaustech-enroll-dash.vercel.app/

This project is a school project developed to demonstrate frontend development skills using modern tools and frameworks. It serves as an enrollment dashboard concept for OAUSTECH.

Getting Started

To run the project locally, ensure you have Node.js and npm installed. If not, you can install them via nvm
.

Follow these steps:

# Step 1: Clone the repository using the project’s Git URL.
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory.
cd <YOUR_PROJECT_NAME>

# Step 3: Install the necessary dependencies.
npm install

# Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev
